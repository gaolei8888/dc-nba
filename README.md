# NBA 赛季预测中心

一个本地运行的 NBA 数据与比赛预测应用：涵盖 30 支球队的基础/高阶数据、全联盟球员数据、
2026-27 赛季完整官方赛程，以及基于 Elo + 效率评级 + 阵容影响力的比赛预测与赛季蒙特卡洛模拟。

## 快速开始

```bash
npm install
npm run ingest      # 从 stats.nba.com 抓取数据，约 40 秒
npm start           # 构建前端并启动服务 → http://localhost:5174
```

开发模式（前端热更新）：

```bash
npm run dev         # 前端 http://localhost:5173，API 5174
```

## 功能

| 页面 | 内容 |
| --- | --- |
| 总览 | 30 队实力榜（综合实力 / Elo / 净效率 / 攻防 / 节奏）、揭幕战预测、模型说明 |
| 球队 | 按分区或赛区分组的球队卡片 |
| 球队详情 | 球队基础与高阶数据、四要素、得分构成、完整阵容（可切换基础/高阶）、全季赛程与逐场预测 |
| 球员 | 680 名球员的基础数据与高阶数据，支持搜索、按球队/位置/出场数筛选、任意列排序 |
| 赛程 | 2026-27 完整赛程（1200 场常规赛 + 季前赛），每场附主队胜率、预测比分与总分 |
| 比赛预测 | 任选两队或指定赛程场次，输出胜率、让分、总分、比分，并给出分差来源拆解 |
| 赛季模拟 | 蒙特卡洛模拟整个常规赛，输出预计战绩、胜场区间、季后赛/附加赛/分区头名概率 |

**缺阵模拟**：在球队页或预测页勾选球员即可标记缺阵，该设置全站共享，会同步影响实力榜、
赛程胜率、单场预测和赛季模拟。

## 预测模型

球队实力统一折算成「相对联盟平均的每场净胜分」：

```
实力 = (Elo折算分 × wElo + 净效率折算分 × wNet) / (wElo + wNet) + 缺阵修正
分差 = 主队实力 − 客队实力 + 主场优势 + 休息修正
胜率 = Φ(分差 / 分差标准差)
```

- **Elo**：用上赛季 1230 场逐场结果迭代（K=20，含 538 式分差放大项，中立场不给主场优势），
  赛季间按 `0.75 × Elo + 0.25 × 1500` 向均值回归，模拟球员流动与均值回归。
- **净效率**：上赛季百回合净效率 × 节奏 / 100，折算成每场分差。
- **缺阵修正**：球员影响力取 `(PIE − 0.085) × 出场时间`（小样本向替补级收缩），
  再用 30 队做 `净效率 ≈ a + b × Σ影响力` 的最小二乘回归换算成分数。
  缺阵球员的影响力下限为 0——替补顶上最差也就是替补级水平，缺人不会让球队变强。
- **休息修正**：背靠背 −1.1 分，休 2 天 +0.35 分，休 3 天及以上 +0.5 分。
- **比分**：由双方进攻/防守效率对位（`己方进攻 + 对手防守 − 联盟平均`）与节奏推出总分，
  再按预期分差拆分成两队得分。
- **赛季模拟**：每次模拟先给每队抽一个标准差 2 分的实力扰动（代表赛季前评估本身的误差），
  再逐场按胜率抽样。默认 3000 次。

模型参数（主场优势、Elo/净效率权重、休息强度、缺阵强度、分差标准差）都可以在
「比赛预测 → 模型参数」里实时调整，调整后全站生效。

## 已知局限

- 基准数据是上赛季表现，**不包含新秀与夏窗签约球员的产能预估**。新援会出现在最新名单里，
  但如果上赛季没有 NBA 出场记录，其影响力按 0 计算。
- PIE 对无球防守、组织牵扯的估值偏低，防守型球员的缺阵影响会被低估。
- 赛季模拟的分区排名用随机数打破平局，未实现 NBA 官方的相互战绩等平局规则。
- NBA 杯淘汰赛（6 场）为待定对阵，不参与模拟；因此每队排定场次为 80 场而非 82 场。

## 项目结构

```
scripts/ingest.mjs      抓取并归一化数据 → data/*.json
server/
  nbaClient.mjs         stats.nba.com 客户端（浏览器请求头 + 串行限速 + 重试）
  ratings.mjs           Elo 计算、阵容影响力回归
  predict.mjs           预测引擎（单场预测、赛程批量、赛季模拟、实力榜）
  teamMeta.mjs          30 队中文名与队色
  index.mjs             Express API + 静态资源托管
web/src/                React 前端（极简 hash 路由，无额外路由库）
data/                   抓取产物（已 gitignore）
```

## API

| 接口 | 说明 |
| --- | --- |
| `GET /api/meta` | 赛季信息、默认参数、数据量 |
| `GET /api/teams` · `GET /api/teams/:id` | 球队列表 / 球队详情（含阵容与带预测的赛程） |
| `GET /api/players?teamId=&onRoster=1` | 球员数据 |
| `GET /api/schedule?type=&teamId=&from=&to=&limit=` | 赛程（默认带预测，`predict=0` 关闭） |
| `GET /api/rankings` | 实力榜 |
| `POST /api/predict` | 单场预测 `{homeId, awayId, gameId?, neutral?, out?, params?}` |
| `POST /api/simulate` | 赛季模拟 `{sims?, out?, params?, seed?}` |
| `POST /api/refresh` | 重新抓取数据并热加载（约 40 秒） |

GET 接口可用 `?out={"teamId":[playerId]}`（JSON 字符串）传入缺阵名单，
以及 `?homeAdv=3&wElo=0.6` 等参数覆盖。

## 数据更新

新赛季开打后重新抓取即可自动切换基准赛季：

```bash
npm run ingest
# 或指定赛季
PRIOR_SEASON=2026-27 TARGET_SEASON=2027-28 npm run ingest
```

数据来源为 NBA 官方 stats.nba.com，仅供个人学习研究使用。
