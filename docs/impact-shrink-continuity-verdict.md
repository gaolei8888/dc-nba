# IMP 按分钟收缩 × 延续度加权 Elo：实验结论（2026-10-28）

**结论：**

- **实验 1（IMP 按出场分钟收缩）：按预注册规则通过。** 但通过的不是原设想的「向 SPM 收缩」（形式 A，单调变差），而是「整个 IMP 按出场分钟向人群均值收缩」（形式 C）。本分支已在 `scripts/ingest.mjs` 接入，未合并、未上线。
- **实验 2（延续度加权 Elo × 阵容估计）：不采纳。** 留一赛季 Δlog loss −0.0003 [−0.0016, +0.0011]，区间含 0。最终留出季 +0.0020，方向相反。
- **附带发现（比两个实验都大）：线上 IMP 现在是纯 SPM，没有混入 APM。** 本机快照 `players.json`（fetchedAt 2026-10-28T02:43Z）里 406 名有 IMP 的球员，IMP 全部恰等于纯 SPM。原因是做全量 ingest 的这台机器 `data/history/` 里没有 `lineups_*.json`。`deploy/push-refresh.sh` 只检查 `data/history/` 目录存不存在，ingest 只打一行警告就继续。Thybulle 的 +4.45 全部来自统计栏，他的 APM 那一半是 +1.86。

## 实验 1：IMP 按样本量收缩

### 问题

上季 IMP 不随样本量收缩。Thybulle 2025-26 只打 30 场 × 16 分钟（480 分钟），IMP +4.45，比东契奇（2291 分钟，+3.91）还高。湖人因此在阵容榜排到第 3。

### 方法（`server/impactShrink.mjs`，`scripts/impact-shrink-lab.mjs`）

判据沿用 `fit-impact` / `impact-lab` 的「用第 N 季预测第 N+1 季」，两把尺子：

- 次季真实 APM（单季，λ=6000）
- 次季裸 on/off（独立尺子）

球员范围与 `fit-impact` 的 `rowsFor` 相同：两季 APM 回合都 ≥500，当季 ≥20 场且场均 ≥10 分钟，每对约 333 人。SPM 训练时看不到第 N 季。现状基线复现了 `impact-model.json` 里 IMP 的验证成绩（次季 APM 平均 0.4569）。

试过的形式（都是 `(n·值 + k·目标)/(n+k)`）：

| 形式 | 收缩什么 | 收缩目标 | n（证据量） | k 网格 |
|---|---|---|---|---|
| A | IMP 里实测（APM）那一半 | 该球员的 SPM | 衰减 APM 回合数 | 0, 250 … 64000 |
| B | SPM 本身，然后再混合 | 人群 SPM 均值 | 上季出场分钟 | 0, 100 … 12800 |
| C | 混合后的整个 IMP | 人群 SPM 均值 | 上季出场分钟 | 0, 100 … 12800 |
| A+B | 两者叠加 | — | — | 10×9 |
| ★ | 以上全部候选一起选 | — | — | — |

- k 的选择用**留一赛季对**：在另外 3 对上按两尺平均选 k，只在留出那对上打分。
- **形式本身**也按同一协议参与选择（★ 行），防止看完结果再挑形式。

**预注册规则**：按留一赛季对的结果，两把尺子的平均都要变好，且任一尺子输的赛季对不过半。另外报告更严的口径（最多输 1 对）。

### 结果（留一赛季对，Δ > 0 表示更好）

| 形式 | 选中的 k（4 折） | Δ 次季 APM | 输的对数 | Δ 次季 on/off | 输的对数 | 规则 |
|---|---|---:|---:|---:|---:|---|
| A 向 SPM 收缩 | 4 折都是 0（不收缩） | 0.0000 | 0/4 | 0.0000 | 0/4 | **不通过**：k>0 单调变差，k=16000 时 −0.035 / −0.017 |
| B SPM 向均值收缩 | 800, 800, 400, 400 | +0.0060 | 0/4 | +0.0030 | 1/4 | 通过 |
| **C IMP 向均值收缩** | **3200 ×4** | **+0.0136** | **0/4** | **+0.0090** | **0/4** | **通过（严口径也通过）** |
| A+B | 16000/6400 ×3, 8000/3200 | +0.0129 | 0/4 | +0.0111 | 0/4 | 通过 |
| ★ 全部一起选 | 同 A+B | +0.0129 | 0/4 | +0.0111 | 0/4 | 通过 |

形式 C 的逐对结果：

| 留出对 | 次季 APM 现状 → C | Δ | 次季 on/off 现状 → C | Δ |
|---|---|---:|---|---:|
| 2021-22→2022-23 | 0.4516 → 0.4591 | +0.0075 | 0.3635 → 0.3754 | +0.0119 |
| 2022-23→2023-24 | 0.4728 → 0.4919 | +0.0191 | 0.3487 → 0.3500 | +0.0014 |
| 2023-24→2024-25 | 0.4699 → 0.4816 | +0.0117 | 0.2603 → 0.2804 | +0.0201 |
| 2024-25→2025-26 | 0.4333 → 0.4493 | +0.0160 | 0.3342 → 0.3367 | +0.0025 |

- 形式 C 的 k 在 1600–12800 分钟之间很平，样本内两尺平均从 0.4027 到 0.4031，选点不脆弱。
- 形式 B 输掉的那一对是 2022-23→2023-24 的 on/off（−0.0057）。
- 形式 C 在 on/off 尺子上最弱的两对只有 +0.0014、+0.0025，接近噪声。

**采用 C 而不是 A+B 的理由**：两者的留一对成绩相当（APM 尺子 C 略好，on/off 尺子 A+B 略好），C 只有一个参数，而且 4 折选的 k 完全一致。这一步是在结果出来后做的「同等成绩取简」，不是预注册的；★ 行给出的是不经人挑选的成绩，同样通过。

### 为什么「向 SPM 收缩」反而变差

Thybulle 这类球员的问题不在 APM，而在 SPM 本身：每 36 分钟的抢断和干扰球在 480 分钟上同样是噪声。他的 SPM 是 +4.45，APM 是 +1.86（已乘量纲），所以向 SPM 收缩会把他**往上推**。另外，`computeApm` 本身已按回合数做岭回归向 0 收缩，再向 SPM 收缩等于把 APM 那一半里的信息丢掉，所以形式 A 单调变差。

真正起作用的是：**上场时间本身就是信息**。教练只给 16 分钟，这件事本身说明了他的真实水平，所以小样本球员整体应该向人群均值靠。

### 量纲（只定单位，不参与选 k）

相关系数与量纲无关，但阵容榜要把 IMP × 分钟直接加总，所以单位必须定下来。收缩后，「次季目标对预测值」的合并斜率是现状的 3.016 倍（次季 APM 尺子）和 3.001 倍（次季 on/off 尺子），两把尺子一致。所以最终公式补乘一个常数：

```
IMP' = μ + (IMP − μ) · m/(m+3200) · (1600+3200)/1600        m = 上季出场分钟，μ = 人群 SPM 均值
```

- 打满 1600 分钟的人不变。
- 480 分钟的人保留 39% 的偏离。
- 2600 分钟的人放大到 1.34 倍。

这个放大不是凭感觉加的：现状 IMP 的整体斜率只有 0.63，因为小样本球员的离散度太大，把斜率压平了，大样本球员的偏离其实被低估了。

### 比赛层面旁证（不是预注册判据）

在实验 2 的回测里只换球员价值（同一模型族，各自调 a、sd，留一赛季）：

| 模型族 | 阶段 | 场数 | IMP 原值 | 收缩 IMP | Δ [95% CI] |
|---|---|---:|---:|---:|---|
| 纯阵容 | 全部 | 4920 | 0.6390 | 0.6385 | −0.0005 [−0.0018, +0.0008] |
| 纯阵容 | 已赛 <10 | 623 | 0.6226 | 0.6219 | −0.0006 [−0.0045, +0.0031] |
| 延续度混合 | 全部 | 4920 | 0.6140 | 0.6139 | −0.0002 [−0.0005, +0.0001] |

方向一致，幅度在噪声里。比赛层面证明不了它，但也没有反对它。

### 接入（本分支，未合并）

- `scripts/ingest.mjs`：上季 IMP 算出后，用 `shrinkByMinutes` 收缩。μ 取本次快照里够门槛球员 SPM 的简单均值。收缩前的值保留在 `p.impactUnshrunk`。
- 本季混合 `currentImpact`（K=20 场）的先验自然变成收缩后的值。本季那一段**没有另做收缩**：本季分段的统计栏没有历史缓存，验证不了。
- `impact-model.json` 的 `validation` 没有重算。界面上 ImpactValidation 显示的仍是收缩前 IMP 的成绩，需要另跑 `npm run impact:fit` 并决定是否把收缩版列入候选。

## 实验 2：延续度加权 Elo × 阵容估计

### 方法（`server/continuityLab.mjs`，`scripts/continuity-backtest.mjs`）

```
强度 = w·Elo 分 + (1−w)·a·阵容分
w    = f(延续度 c)
c    = 该队最近 82 场（本季不够就用上季补）的上场分钟里，由当前名单球员打的比例
```

赛季中 c 会自然上升：本季的分钟都是现名单打的。所以「w 随本季场次增长」已经包含在 c 里。

**防泄漏**（可行性：用 stints + impact 缓存能做到，不需要任何新抓取）：

- 第 N 季的比赛只用第 N−1 季的球员价值。SPM 只在 ≤N−1 季上训练，APM 只用 ≤N−1 季的组合，量纲校准也只用 ≤N−1 季。
- 当前名单 = 本季在当场之前为该队出过场的人；之后为别队出场即移出。
- **唯一的近似**：每队本季第一场的名单，用当场出场的人代替开赛日现役名单。这泄露了「第一场谁健康」，只影响 120 个队季里每队的第一场。
- 预计分钟用阵容榜同一套 `projectMinutes`：上季场均 + 本季此前场均与出场率。这套常数是在 2021-26 的 stints 上拟合的，对分钟模型而言是样本内；它不涉及比赛结果。
- 联盟平均阵容分取上季分钟加权均值，赛前就能算。
- 2024-25 有 15 场、2025-26 有 6 场，至少一队还没有可用名单（该队开季前几场缺 stint），这些比赛退回纯 Elo。两队都有阵容分的比赛占 98.8–100%。其余缺 stint 的比赛（约 3%）只是不更新名单与分钟。
- 各队本季第一场的延续度：最低 0.17，中位 0.59，最高 0.86（114 个队季；6 队的首场缺 stint）。

**模型族**（每族都在训练季上按 log loss 选 a ∈ {0.5…1.5}、sd ∈ {11…13}、球员价值 ∈ {IMP 原值, 收缩 IMP}）：

| 模型族 | 权重形式 | 参数网格 |
|---|---|---|
| roster | w=0 | — |
| const | 固定 w | w ∈ {0.25, 0.5, 0.75} |
| pow | w=c^γ | γ ∈ {0.5, 1, 2, 4} |
| lin | w=1−β(1−c) | β ∈ {0.5, 1, 1.5, 2, 3} |

- ★ 是全部 655 组候选按训练 log loss 一起选出的。
- 协议与融合实验完全相同：2021-22 只做热身；留一赛季 2022-23~2025-26；最终留出为训练 2022-25、只在 2025-26 打分一次；与生产 Elo（sd=12）在相同比赛上按场配对 bootstrap（2000 次）。
- 盘口只作参照列，不参与任何拟合或选择。

**预注册规则**：只有满足以下两条才采纳：

1. 留一赛季全部比赛的 Δlog loss 区间不含 0；
2. 最终留出季与之同号。

**窗口敏感性**（CONT_WINDOW=41，同协议）：

- 留一赛季 −0.0000 [−0.0013, +0.0012]，最终留出 +0.0014 [−0.0016, +0.0045]，结论相同。
- 10–19 场阶段同样变差：留出季 +0.0135 [+0.0038, +0.0235]。

### 判断

1. 按预注册规则**不采纳**：留一赛季区间含 0，留出季符号相反。
2. 唯一一致的正向迹象在开季（<10 场）和低延续度比赛：点估计 −0.003 ~ −0.006，所有区间都含 0。这正是这个机制该起作用的地方，但效应小到 4 季数据测不出来。
3. 10–19 场阶段两套协议都变差（留一赛季对调 sd 的 Elo 显著），留出季显著变差。可能的原因：上季球员价值在本季十几场后已经不如滚动 Elo 准，而 c 在这一阶段仍然偏低（82 场窗口里本季场次少），给了阵容分太多权重；41 场窗口也没有改善，所以不只是窗口长短的问题。函数形状与证据不符，与融合实验的教训一样。
4. **「CHA、ATL 换血大」这个前提，按分钟延续度看并不成立。**
   - 当前名单打了这两队近 82 场分钟的 63% 和 72%；同一个窗口下，开季首场延续度的历史中位数是 0.59。
   - 延续度最低的是 LAL 0.42、LAC 0.51、MEM 0.54、CHI 0.57、PHI 0.58。
   - 旧 Elo 榜把 CHA、ATL 排得高，主要来自 Elo 本身（上季末段和本季开局），不是延续度能解释的。

## 局限与没做到的

1. **实验 1 的 k 是在全部 4 个赛季对上（留一对）选的。** 实验 2 回测 2022-23 时用的收缩参数，用到了 2022-23 之后的球员数据（只涉及球员层面的次季表现，不涉及比赛结果）。没有更早的赛季，做不到严格前向。
2. **形式 C 的选择发生在看到 A、B 的结果之后。** ★ 行（全部候选一起按留一对选）给出的是不经人挑选的成绩，同样通过。
3. **两把尺子都限定在 ≥20 场、≥10 分钟、两季 APM ≥500 回合的球员。** 真正样本最小的人不在评估集里，收缩在他们身上的效果没有被检验，只能外推。
4. **本季混合（K=20 场）没有动**：本季分段的统计栏没有历史缓存。
5. **实验 2 每队第一场的名单用当场出场名单近似**（见方法）。分钟模型常数对 2021-26 是样本内。
6. **没有建模**交易截止日、伤停名单（只靠「此前出场」滞后反映）和新秀价值（统一用 −0.5 替补级先验）。
7. **线上 IMP 缺 APM 的问题本分支没有修。** 要修就得让全量 ingest 的机器有 `data/history/lineups_*.json`（GB10 上有），或在 `push-refresh.sh` 里检查 lineups 文件而不只是目录。动部署脚本和线上数据不在这次范围内。
