## 正文（descMd）草稿

```markdown
一个可以直接玩的 NBA 数据应用。数据全部来自 NBA 官方接口，不是模拟数据。

### 能做什么

- **看懂一支球队**：30 支球队的基础与高阶数据、四要素、得分构成，
  680 名球员的场均与效率数据，2026-27 赛季完整官方赛程 1200 场。
- **预测每一场比赛**：胜率、让分、总分、比分，并给出分差从哪来的拆解——
  Elo 差多少、净效率差多少、主场值几分、背靠背扣几分。
- **模拟整个赛季**：蒙特卡洛跑几千次常规赛，得到每队的预计战绩、
  胜场区间与季后赛概率。
- **和模型比准**：对真实比赛做预测，逐日推进、即时翻牌，累计积分与连胜。
  模型的判断是逐日重放生成的——它在每场比赛前只能看到那场之前发生的事，
  和你掌握的信息一样多。

### 模型准不准，有数

大部分预测应用不会告诉你这个。这个应用带一套回测框架：
在 2022-23 到 2025-26 共 4920 场真实比赛上逐场重放，得到的结果是
**胜负命中率 66.3%**（永远选主队是 55.6%，同一批比赛的博彩收盘盘口是 68.4%）。

还能和博彩市场正面对账：在 4908 场有收盘盘口的比赛上，
盘口的胜负命中率是 68.4%，我们是 66.3%——差 2.1 个百分点，而且这个差距在统计上是真的。
模型相对盘口选边的让分命中率只有 49.1%，低于 52.4% 的打平线，
所以应用里明确写着：**分歧值得看，但不构成下注建议**。

回测也否掉过我自己的功能：原本给"夏窗阵容更迭"设的修正强度，
经回测证明是有害的——用它反而让命中率掉 2.5 个百分点，于是降到了原来的五分之一。
能测出来，才敢改。

### 技术

Node + React。数据抓取、Elo 评级、蒙特卡洛模拟、回测框架全部自己实现。
赛季模拟跑在工作线程里，不阻塞其它请求；大响应预压缩后缓存，
出口带宽压掉 92%。

仓库：<填入你的仓库地址>

### 说明

数据来源为 NBA 官方 stats.nba.com 与 ESPN 公开接口，球队标识与球员照片版权归属 NBA。
本作品仅供学习交流。排行榜数据没有备份，可能因服务器重建而重置。
```
