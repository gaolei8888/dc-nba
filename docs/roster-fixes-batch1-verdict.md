## 结论

**采纳。** 预注册规则是「分钟 MAE 优于旧版，且球队层面 log loss 没有显著变差」，两条都满足：

| 指标（2022-23 ~ 2025-26 四季） | 旧版 | 新版 | 朴素基准（本季场均） |
|---|---:|---:|---:|
| 分钟 MAE，report 口径（赛前伤病报告）：全部 | 6.067 | **5.585**（−7.9%） | 6.377 |
| 　首发 / 替补（上场）/ 在册未上场 | 7.145 / 5.977 / 5.335 | 6.234 / 5.720 / 4.984 | 5.128 / 5.473 / 8.084 |
| 分钟 MAE，oracle 口径（已知谁上场）：全部 | 3.749 | **2.987**（−20%） | 3.265 |
| 　首发 / 替补 | 6.294 / 5.908 | 4.500 / 5.158 | 5.117 / 5.464 |
| 球队 log loss（纯阵容分，留一赛季），report 口径 | 0.6349 | 0.6339 | 0.6364 |
| 　Δ vs 旧版 [95% CI]（按场配对 bootstrap，n=4776） | — | −0.0010 [−0.0025, +0.0004] | +0.0014 [−0.0001, +0.0029] |
| 球队 log loss，oracle 口径 | 0.6319 | 0.6311（Δ −0.0008 [−0.0020, +0.0003]） | 0.6321 |

新版在每一季都优于旧版（report 口径逐季 5.65/5.42/5.63/5.65 对 6.23/5.81/6.09/6.14）。
2025-26 是轮换概率 q、上限 C、DNP 阈值都没见过的留出季：5.648 对 6.141。
球队层面方向是好的，但区间含 0，**不能说球队预测变好了**，只能说没有变差。

朴素基准的首发 MAE 最低（5.13），因为它不打折：首发按定义上了场，场均分钟就是最好的点估计。
可一旦算上在册却没上场的人（8.08），它整体是三者里最差的。阵容榜要的是期望分钟（会乘到球员价值上），所以看「全部」。

## 回测怎么做的

- 每场每队，只用**赛前**信息预测每名候选球员的本场分钟：上季出场时场均（≥10 场）、本季此前的出场场数与出场时场均（跨队累计，同线上 `p.cur`）、球队已赛场数。
- 出场信息两种口径：
  - **report**：当天北京 22:00 那份官方伤病报告（与 injury-lab 同一条报告链：当天 22:00，退到前一天 06:30；延迟 15 分钟）。这是线上的真实处境。7912/9552 个队·场有可用报告，报告行姓名匹配 99.1%。
  - **oracle**：赛后知道谁上了场，只考察分钟怎么分。
- 候选名单（近似「在册」，所有方法共用）：上季最后效力本队、且本季第一次出场也为本队的人，从第 1 场起在册；其他人从首次为本队出场前 5 场起在册；后来为别队出场的，在为本队打完最后一场后离册。这里借用了「将来为谁出场」来近似在册名单（线上名单本来就是已知的），对所有方法都一样。
- 真实分钟按每场全队总分钟缩放到 240（加时赛），没上场记 0。
- 球队层面：阵容分 = Σ 价值 × 分钟 / 48。价值用上季收缩 IMP，与 `continuity-backtest` 的 `shrunk` 同口径：SPM、APM 和量纲都只用 ≤N−1 季。替补级取 −0.5。预测净胜分 = a·(主 − 客) + 主场 1.6 + 休息，a 和 sd 在其余三季上按 log loss 选。
- 消融（report 口径的「全部」MAE）：
  - 伤病情形逐一枚举（new-enum）5.587，与平均场 5.585 几乎相同，线上用更简单的平均场。
  - 去掉轮换概率 q（new-noq）6.113，比旧版还差。**只改成出场时分钟是不够的**：伤病报告之外，「教练用不用这个人」本身就是一大块信息。
  - 保留新的分钟和概率、换回旧的等比分配（new-prorata）5.737，并且有 5 个队·场分配失败。

## 逐条修复

### 1. 伤病空出的分钟按比例分、单人上限 48

**新做法**（`server/rosterProjection.mjs` 的 `fillMinutes` / `projectExpectedRotation`）：
- 每人期望分钟 = w·C·σ(θ + c)，其中 θ = logit(出场时分钟 / C)，w 是出场概率，c 是全队共用的一个平移量，二分求解让总和恰好等于 240。
- 平移 c 时每人分钟的变化与 σ(1−σ) 成正比：接近上限的主力几乎不动，空出的分钟主要流向轮换中段和替补（下一个顶上的人）；人多分钟不够时，被压缩的也主要是替补。
- 所有人拿满 w·C 还凑不够 240（轮换耗尽）时，余下部分记为替补级分钟（−0.5），**全队总和恒为 240**。

**上限 C = 38**。这里分的是期望分钟（一场的平均），不是单场上限。依据 stints 2021-22 ~ 2025-26 中常规时间打满 48 分钟的比赛：
- 首发单场分钟：p90 37.0–38.1、p95 38.5–39.4、p99 40.7–42.1；
- 出场 ≥40 场球员的赛季场均最高只有 37.0–37.4，每季场均 ≥36 分钟的只有 2–6 人。

38 略高于历史最高的赛季场均，约等于首发单场的 p90。训练季上 36 到 42 的 MAE 差别不到 0.03（36/37/38/40/42 → 5.563/5.561/5.565/5.574/5.584），曲面很平，所以按历史分位数取值，没有按 MAE 选最优。

**同位置优先没有做**：`data/history` 的 impact、players 文件里没有位置字段，验证不了，所以没有加。

当前 OKC：Gilgeous-Alexander 28.2 → 43.3（旧）变成 32.1 → 36.2（新）；缺 J. Williams、Holmgren、Wallace、Caruso，rosterAdj 从 −0.53 变成 −3.91。

### 2. 分钟被压缩，没出场的人照拿分钟

**新做法**（`server/rotationMinutes.mjs`）：期望分钟 = 出场时分钟 × 轮换概率 q × 伤病出场概率，三部分分开估：
- **出场时分钟**：只收缩出场时的 MPG，常数沿用 `roster-shrinkage.mjs` 对出场时 MPG 的拟合（向上季场均收缩 K=2.5；无先验的向 7 + 0.7·本季MPG 收缩 K=16），不再乘「向 0.60 收缩的出场率」。
- **轮换概率 q** = P(健康时上场)，即教练用不用他：
  - 形式：q = logistic(−0.979 + 1.168·min(m,36)/10 + 0.670·[无分钟信息] + 0.518·logit ρ)，其中 ρ = (min(n,T)+0.75)/(T+1)。
  - 拟合样本：有报告、且不在名单上（或 Available / Probable）的候选球员·场，训练 80349 行。2025-26 留出 log loss 0.372，常数基准 0.543。
  - 经验分档：出场时 30+ 分钟的人 97% 上场，20–25 分钟 91%，10–15 分钟 60%，5–10 分钟 39%。
- **DNP-CD**：本季 0 出场、球队已赛 ≥2 场、又不在伤病名单上，就判为轮换外，出场时分钟降到 1（只在轮换耗尽时才会被抬起来）。
  - 在训练季上，阈值 1 / 2 / 3 / 不用对应 MAE 5.559 / 5.565 / 5.572 / 5.613。阈值 1 只好 0.006，但会把开幕夜一场未上的人直接判出轮换，所以取保守的 2。
  - 在伤病名单上的 0 出场按伤停处理：保留上季角色，再按伤病概率打折。
- **健康和已报两种模式的含义一致**：「忽略已报伤病」= 没有人受伤，但 q 照用（那是教练的决定）；「计入已报缺阵」= q × P(出场|状态)。两种模式下 healthyTotal 相同，并且等于健康模式的 total（有测试锁定）。

回测检查（report 口径；本季此前场场出场、出场时场均 ≥32 的人，本场上了场时）：实际 33.6 分钟，旧版预测 32.8，新版 33.3。

当前快照：联盟健康分钟最高值从 30.8 变成 36.6。本季 0 出场却拿到 ≥8 分钟的人从 17 个变成 0 个：Julian Reese 15.7 → 0.8，Malachi Smith 14.8 → 0.8，Micah Peavy 11.5 → 1.4。

### 3. 伤病只有 out 一档

改为用冻结的 `server/injury-params-v1.json`（slot '22'），没有重拟合。ESPN 状态对应关系：
- out → Out，0.0109
- doubtful → Doubtful，0.0631
- dayToDay（GTD）→ Questionable，0.5416
- 不在名单上 → 1

选 slot '22' 是因为 ingest 在 UTC 14 点前后（美东上午）抓 ESPN，与 22:00 那个时点的口径一致。手动勾选的缺阵仍然记硬 0。

注意：0.54 这些概率是在「常规轮换球员」身上拟合的，四个评估季里有训练季，所以 report 口径的回测对伤病概率这一项是部分样本内的。冻结的参数本来就来自这些季，这里没有再调。

### 6. 小问题

- **去均值不一致**（旧版从期望阵容分里减去健康均值，导致联盟均值 −0.17）：现在每种模式都用该模式自己的联盟均值，而且先折成每场分差（× 节奏 / 100）再去均值，所以联盟均值恰好为 0（当前快照 −0.000）。均值不含手动缺阵，勾掉某队的球员不会牵动别队（有测试）。
  - `rosterAdj` 现在是绝对的伤病代价（期望 − 健康，不去均值）。所以 total = healthyTotal + rosterAdj + 一个全联盟相同的常数（两种模式均值之差）。
- **缺失的拼抢数据按 0 计**：`impact.features` 标出拼抢表里缺这个人的情况（三项都是 null，而不是 0）。`apply` 打分时这三项按人群均值处理（标准化后为 0）。训练样本照旧记 0：每季只有 1–9 行缺，改训练会牵动已经验证过的 IMP 系数。当前快照有 25 名球员的本季拼抢数据缺失，下次 ingest 后他们本季 SPM 的这三项不再被当成 0。

## 局限与没做的事

- 线上快照只有本季累计数据（场数、场均），没有逐场记录，所以 DNP-CD 只能识别「一场都没打」。打过几场后连续 DNP 的人看不出来，只能由 q 里的出场率 ρ 部分反映。ρ 里也混有过去的伤停，所以伤愈归来的人的 q 会偏低一点。
- 同位置优先没有做（历史数据里没有位置字段，无法验证）。
- q、C、DNP 阈值是在 2022-23 ~ 2024-25 上选的，四季合计的 MAE 有三季是样本内；2025-26 是干净的留出季（5.648 对 6.141）。伤病概率表见第 3 条。
- 球队层面的改善不显著，阵容榜预测比赛的能力并没有得到证明。比赛胜率仍然来自 Elo，界面上已写明。
- 回测的候选名单是近似的（见「回测怎么做的」），但对所有方法相同。
- 平均场近似：出场概率是小数时，不逐一枚举谁上谁不上。与枚举的差别是 MAE 0.002。
- 拼抢缺失的修复只改打分、不改训练；IMP 验证文档里的数字可能在小数点后第三四位变动（每季 1–9 行受影响），没有重跑那些实验。
