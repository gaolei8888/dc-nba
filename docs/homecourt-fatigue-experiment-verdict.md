# 主场 × 疲劳实验结论（2026-10-27）

**结论：八个因子都不采纳，线上参数不变。**

- 单独加到生产模型上时，没有一个因子在留一赛季交叉验证里显著降低 log loss。
- 按协议嵌套选出的组合在留一赛季里**显著更差**：Δlog loss +0.0012 [+0.0002, +0.0021]。
- 现有的「主场 1.6 + 休息表 ×1.8 + Elo 更新主场 100」已经吃掉了这类赛程信号中能稳定利用的部分。剩下的效应在 ±0.5 分量级，样本量撑不起来。

本次没有改动线上的 `server/predict.mjs` DEFAULT_PARAMS，也没有改 `server/ratings.mjs` 的 `ELO_HOME_ADV`。

复现：`node scripts/homecourt-fatigue-experiment.mjs`，约 7 秒，纯离线。只读 `data/backtest.json`、`data/history/stints_*.json.gz`、`data/history/books_*.json`、`data/teams.json`。
测试：`node --test tests/homecourtLab.test.mjs`。

## 问题

在生产模型之上，下面这些因子有没有样本外的增量价值？

- 生产模型：滚动 Elo；预测主场 1.6 分；休息表 `0:−1.1, 1:0, 2:+0.35, 3:+0.5` ×1.8；Elo 更新主场 `ELO_HOME_ADV=100`，约合 3.6 分；sd=12。
- 主场类：
  - H1：Elo 更新里的主场改成与实测一致。
  - H2：球队专属主场。
  - H3：旅行、时差、高原。
- 疲劳类：
  - F1：赛程密度。
  - F2：背靠背情境。
  - F3：上一场加时。
  - F4：核心球员负荷。
  - F5：客场之旅。

## 方法

纯逻辑都在 `server/homecourtLab.mjs`，并有测试锁定。场馆静态数据在 `server/arenas.mjs`：30 座主场的经纬度和 IANA 时区，都是公开地图资料；高原主场是 DEN（约 1609 米）和 UTA（约 1288 米）。

**所有特征只用开赛前已知的信息。** 赛程本身提前公布；分钟和加时都取自更早的比赛。

| 因子 | 定义（主队视角 = 主 − 客；系数 = 对「该队」每单位的分数影响） |
|---|---|
| H1 | `computeElo` 新增可选参数 `homeAdv`，默认仍为 100。候选值：1.6 / 2.0 / 2.4 分（×28 Elo）；上季实测主场净胜分（只用更早数据，依次为 1.72 / 2.50 / 2.15 / 1.69）；上季实测同时用于 Elo 和预测。由训练季 log loss 挑选，也可以选回生产值。 |
| H2 | 每队取「此前比赛中主场平均残差 − 客场平均残差（本队视角）」的一半，减去联盟均值，再乘 `n/(n+K)` 收缩，其中 `n = 1/(1/n主 + 1/n客)`。本场调整 = a主 + a客。滚动计算，只用当天之前的比赛（含 2021-22 热身季）。K ∈ {25…800} 或不启用，由训练季 log loss 挑选。 |
| H3 | 从上一场地点到本场的里程（每千英里）、时区差（小时，绝对值，用 `Intl` 处理夏令时；菲尼克斯不实行夏令时）、客队进高原。 |
| F1 | 四天三赛、六天四赛（都含本场）。 |
| F2 | 背靠背且在客场；背靠背之间的旅行里程；背靠背进别人的高原主场。 |
| F3 | 上一场加时节数（由 stints 总秒数 − 2880 得出）；该节数 × 背靠背。 |
| F4 | 核心三人取近 10 场分钟最多的 3 人，计算他们最近两场的分钟 − 2×各自窗口场均（单位：每 10 分钟）。窗口少于 4 场或缺 stints 时记 0。stints 覆盖率 95–98%。 |
| F5 | 本次客场之旅已打场数（含本场）；本次客场之旅累计里程。 |

- 中立场的地点未知，所以里程、时差、高原都不计，双方都算客场。快船 2024 年迁馆约 15 公里，不区分。
- **拟合**：因子系数用训练季的净胜分残差（实际 − 生产预测）做最小二乘。特征按训练集均值中心化，所以斜率等同于带截距的回归。
  - 必须这样做的原因：客队几乎总是在旅行、总在客场之旅中，这些特征恒为正。不中心化的话，它们会偷偷把主场优势整体调高。
  - 首版就踩到了这个问题，已加测试锁定。整体调主场是 H1 要回答的问题。
- H1 和 H2 的离散超参按训练季 log loss 选。**选择标准只有比赛结果。**
- **协议**：
  - 2021-22 只作热身。
  - 留一赛季：在 2022-23 ~ 2025-26 上逐季留出，再合并。
  - 最终留出：用 2022-25 训练，只在 2025-26 打分一次。
  - 与生产模型在完全相同的比赛上比较，按场配对 bootstrap 求 95% 区间（2000 次，固定种子）。
  - 阶段按两队中较少的已赛场次划分。
- **组合**：在每个外层训练集内部再做一次留一赛季，内层 log loss 好于生产的因子才入选。留出季不参与选择。另报一个「全部因子、不做选择」作对照。
- 盘口只作事后诊断，不作为特征、目标，也不用来选参。
- 自检：脚本启动时断言，生产口径的基础预测与 `lab.replay` 在 4920 场上逐场一致。

## 结果（Δ = 候选 − 生产，< 0 表示更好）

### 留一赛季（4920 场；生产 log loss 0.6141，Brier 0.2130，准确率 66.32%，MAE 10.908）

| 模型 | Δlog loss [95% CI] | ΔBrier | Δ准确率（百分点） | Δ分差 MAE |
|---|---|---|---|---|
| H1 Elo 主场一致 | 0（4 折都选回生产值 100） | 0 | 0 | 0 |
| H2 球队专属主场 | +0.0003 [−0.0004, +0.0011] | +0.0002 [−0.0001, +0.0005] | **−0.49 [−0.93, −0.06]** | +0.007 [−0.005, +0.018] |
| H3 旅行/时差/高原 | +0.0002 [−0.0007, +0.0010] | +0.0001 [−0.0003, +0.0005] | −0.04 [−0.47, +0.45] | +0.007 [−0.006, +0.021] |
| F1 赛程密度 | +0.0001 [−0.0007, +0.0009] | +0.0001 [−0.0003, +0.0004] | −0.12 [−0.55, +0.30] | −0.005 [−0.018, +0.009] |
| F2 背靠背情境 | +0.0005 [−0.0000, +0.0011] | **+0.0002 [+0.0000, +0.0005]** | −0.16 [−0.47, +0.14] | +0.004 [−0.004, +0.012] |
| F3 上场加时 | +0.0004 [−0.0005, +0.0013] | +0.0002 [−0.0002, +0.0006] | −0.02 [−0.26, +0.22] | +0.011 [−0.003, +0.023] |
| F4 核心负荷 | −0.0002 [−0.0008, +0.0004] | −0.0000 [−0.0003, +0.0002] | −0.16 [−0.53, +0.20] | +0.001 [−0.009, +0.010] |
| F5 客场之旅 | +0.0003 [−0.0004, +0.0011] | +0.0001 [−0.0002, +0.0005] | −0.28 [−0.71, +0.14] | −0.003 [−0.015, +0.008] |
| 组合（嵌套选择） | **+0.0012 [+0.0002, +0.0021]** | **+0.0006 [+0.0002, +0.0010]** | **−0.47 [−0.91, −0.02]** | +0.014 [−0.001, +0.028] |

分阶段（<10 场 / 10–19 场 / ≥20 场；n = 623 / 612 / 3685）：

- 唯一在某个阶段显著的单因子是 H3 的 10–19 阶段，而且方向是**变差**：+0.0024 [+0.0001, +0.0048]。
- 组合在 <10 阶段显著变差：+0.0025 [+0.0001, +0.0050]。
- F4 在三个阶段的点估计都为负，但三个区间都跨 0。

组合在各折入选的因子：2022-23 {}，2023-24 {F4}，2024-25 {H3, F1, F4}，2025-26 {F2, F4}。入选很不稳定，只有 F4 反复出现。

### 最终留出 2025-26（1230 场；生产 log loss 0.5985）

| 模型 | Δlog loss [95% CI] | ΔBrier |
|---|---|---|
| H1 | 0（选回生产值） | 0 |
| H2（K=100） | +0.0010 [−0.0008, +0.0029] | +0.0005 [−0.0003, +0.0013] |
| H3 | **−0.0011 [−0.0022, −0.0001]** | −0.0005 [−0.0010, +0.0000] |
| F1 | −0.0001 [−0.0016, +0.0014] | −0.0000 |
| F2 | **+0.0022 [+0.0003, +0.0040]** | **+0.0010 [+0.0002, +0.0018]** |
| F3 | +0.0011 [−0.0010, +0.0032] | +0.0004 |
| F4 | −0.0006 [−0.0012, +0.0000] | −0.0002 [−0.0005, +0.0001] |
| F5 | +0.0011 [−0.0006, +0.0028] | +0.0004 |
| 组合 {F2, F4} | +0.0016 [−0.0003, +0.0035] | +0.0008 [−0.0001, +0.0016] |
| 全部因子 | +0.0023 [−0.0017, +0.0065] | +0.0011 |

H3 在留出季显著变好，但留一赛季的结果是 +0.0002 [−0.0007, +0.0010]。四折里只有这一折为负，而且它在 10–19 阶段反而显著变差，所以判为噪声。F2 在留出季显著变差。

### H1 / H2 的固定取值（四季，不经训练）

| 取值 | Δlog loss [95% CI] |
|---|---|
| Elo 更新主场 = 1.6 分（45 Elo） | +0.0004 [−0.0003, +0.0010] |
| = 2.0 分（56 Elo） | +0.0003 [−0.0002, +0.0008] |
| = 2.4 分（67 Elo） | +0.0002 [−0.0002, +0.0006] |
| = 上季实测 | +0.0003 [−0.0002, +0.0008] |
| Elo 与预测都 = 上季实测 | +0.0009 [−0.0001, +0.0020] |
| H2 K=100 / 200 / 400 | −0.0002 [−0.0011, +0.0006] / −0.0002 [−0.0008, +0.0003] / −0.0002 [−0.0005, +0.0001] |

- H1 的「不一致」在数据上反而更好：越接近 100 越好，单调。可能的原因是 K=20 的 Elo 本来就更新不足，较大的主场预期等于把主场赢球打了折扣，从而抑制噪声。不过各个差异都在噪声内。**没有证据支持改动。**
- H2：残差 σ=13.94 分，K=100 对应先验 τ≈0.70 分。用 2021-26 全部数据估计，各队单边主场偏离原始 sd 0.78 分，收缩后 0.39 分。
  - 最高：UTA +0.67、MEM +0.64、OKC +0.51。
  - 最低：PHI −0.92、WAS −0.55、BKN −0.51。
  - 原始 sd 与纯抽样噪声的预期（每队约 205 主 / 205 客：σ/2·√(2/205) ≈ 0.69）几乎相同，扣掉噪声后真实的球队间差异约 0.36 分。

- 13 个系数里出现 1 个 p≈0.04，符合多重比较下的预期。
- 高原效应不显著。在 H2 的球队主场偏离里，UTA 排第一（+0.67，收缩后），DEN 不在前列。

## 诊断（盘口只作事后对照，留一样本外）

| 模型 | 低估自己的热门 | 低估市场热门 | 与收盘 log loss 差距 | 分歧率 ≥3% |
|---|---|---|---|---|
| 生产 | −1.8 个百分点 | −5.4 | +0.0266 | 72.9% |
| 组合 | −1.2 | −5.4 | +0.0278 | 72.9% |
| 全部因子 | −1.0 | −5.4 | +0.0282 | 74.7% |

分差偏置（实际 − 预测）在疲劳场景下确实存在：

| 场景 | 偏置 |
|---|---|
| 客队背靠背 | +0.56 |
| 客队四天三赛 | +0.73 |
| 客队进高原 | +0.71 |
| 客场之旅第 ≥4 场 | +1.15 |

组合模型能把前三项压到 +0.25 ~ +0.52，但整体概率反而变差。这些切片样本小（312–1320 场），修正带来的方差抵消了偏差上的收益。

与市场的差距（约 0.027）完全没有缩小。市场热门被低估约 5.4 个百分点，这个缺口与主场、疲劳都无关。

## 模拟投注重跑（预注册规则不变，只报告）

规则：edge ≥ 3%，平注；扩张窗口，参数和因子只用该季之前的数据选。

| 规则 | 生产 | 组合 |
|---|---|---|
| DraftKings ≥3%（2023-24、2025-26） | 1596 注 ROI −11.8% [−19.3, −4.6] | 1619 注 ROI −12.3% [−18.8, −5.2] |

两者都稳定亏损，组合没有改善。

## 逐项裁决与建议参数

| 因子 | 裁决 | 建议参数 |
|---|---|---|
| H1 Elo 主场一致 | 不采纳 | `ELO_HOME_ADV` 保持 100；`homeAdv` 保持 1.6。四折都选回 100，所有一致化方案的点估计都更差。 |
| H2 球队专属主场 | 不采纳 | 不启用。log loss 区间跨 0，准确率显著 −0.49 个百分点，留出季 +0.0010。 |
| H3 旅行/时差/高原 | 不采纳 | 不启用。留一 +0.0002；仅留出季显著，且与 10–19 阶段的显著变差矛盾。 |
| F1 赛程密度 | 不采纳 | 不启用。现有休息表 ×1.8 已覆盖。 |
| F2 背靠背情境 | 不采纳（有害） | 不启用。留一 Brier 显著变差，留出季 log loss 显著变差。 |
| F3 上场加时 | 不采纳 | 不启用。 |
| F4 核心负荷 | 不采纳（唯一候选） | 线上不变。若在 2026-27 预注册检验，固定为 **−0.011 分 / 超额分钟**，即每 10 分钟 −0.11（四季全量），不再调参。 |
| F5 客场之旅 | 不采纳 | 不启用。「第几场 −0.5 分/场」可以作为单特征假设留给 2026-27 检验，不与里程同时进入。 |
| 组合 | 不采纳 | 嵌套选择后显著更差。 |

线上 `restWeight 1.8`、休息表、`homeAdv 1.6`、`spreadSd 12` 都不变。
