# IMP 回退先验：结论（2026-10-29）

**结论：按预注册规则不采纳。线上不做任何改动。**

两个主检验都要求 Δ log loss 的 95% 区间上界 < +0.0005：

- 阵容榜过了；
- 伤病扣分模型的上界是 **+0.00054**，没过。

差距非常小，这是一个刚好落在线外的结果。但规则写在前面，不因为「差一点」改判。

- 预注册：`docs/superpowers/specs/2026-10-30-imp-fallback-prior-prereg.md`（先于任何回退值和评估数字提交）
- 输出：`docs/imp-fallback-lab-output.txt`
- 复现：`npm run lab:imp-fallback`（纯离线，约 85 秒，不联网）

## 想解决的问题

IMP 只给上季出场 ≥ 20 场、场均 ≥ 10 分钟的人。上季大半时间伤停的球星没有上季 IMP，在回测和伤病扣分里都按替补级 −0.5 算。例如：

- Tatum 16 场；
- Haliburton、Lillard、Kyrie、VanVleet 0 场；
- Walker Kessler 5 场。

本季开打后，他们也要先打满 20 场才有 IMP。

试的规则（用户已批准，没有调参）：

1. 往前最多 3 季，找最近一个「≥ 20 场、≥ 10 分钟」的赛季，按管线方式算出那季的 IMP。
2. 按年龄曲线把这个值平移到上季。
3. 向人群均值收缩：μ + 0.8^g ×（值 − μ）。
4. 上季打过几场的，再按 K=20 把那几场混进来。

## 数字

- 评估：2022-23 到 2025-26，共 4920 场。
- Δ = 回退 − 现状，负数表示回退更好。
- 区间：按比赛日分块 bootstrap，B=2000，seed 7。

**只报告的部分（不参与决策）：**

- **敏感性**：整季缺阵的人再打 0.85 折。结果
  - (a) +0.00016 [−0.00018, +0.00052]
  - (b) −0.00026 [−0.00065, +0.00013]

  与主规则几乎一样，(a) 的上界照样不到线下。
- **受影响比赛**：任一队有轮换球员用的是回退值。
  - (a) 3491 场：+0.0002 [−0.0003, +0.0007]
  - (b) 3891 场：−0.0003 [−0.0009, +0.0002]
- **逐季**：
  - (a) 2022-23 −0.0005，其余三季 +0.0003 / +0.0005 / +0.0003。2023-24、2024-25 两季的区间不含 0，但很小。
  - (b) 2022-23 −0.0009，其余三季在 ±0.0001。
- **覆盖**：每份价值表补上回退值 168–194 人。其中七到八成（74%–86%）是上季根本没有出场记录的人（离开联盟、整季伤停），真正会上场的只是一小部分。

一句话：**对阵容榜略有帮助但不显著；对伤病扣分略有损害，也不显著，而且损害的上界刚好越过预注册的非劣效线。**
整体上，这条规则对预测准确率的影响在 ±0.0005 以内，基本是零。

## 为什么没有用

推测，没有单独验证：

1. **伤病扣分里，回退值只在球员回到健康基线后才起作用。** 健康基线只收本季已经为本队上过场的人。复出初期的伤病报告上，他们常挂 Questionable / Probable，于是回退值直接进了 D_pre。
   - 如果他们复出后的真实水平低于伤前（例如跟腱伤），扣分就会扣多。这次没有建模这一点。
   - 敏感性 ×0.85 只改了整季缺阵的人，(a) 几乎没变，说明问题不只在这一群人身上。
2. **被补上的人大多是边缘球员。** 回退值中位数约 −0.44，和替补级 −0.5 几乎一样。所以绝大多数「受影响比赛」其实没有变化，真正变化的只有少数球星，样本很小。
3. **阵容榜本来就会被战绩修正兜底。** K=12 时，十几场之后先验就不重要了，所以 (b) 的收益也很小。只看阵容（K=∞）时收益大一些（−0.0007），但同样不显著。

## 局限

- **受影响的有效样本小。** 3000 多场「受影响」里，真正价值有明显变化的球星复出场次只占一小部分。这次的检验对「球星复出」这个具体问题的统计功效很低。
- **主规则没有建模跟腱等重伤后的衰退**（Haliburton、Lillard、Tatum 都是跟腱）。敏感性 ×0.85 只是一个粗糙的替代。
- **实验口径对早期赛季有简化。**
  - 合格季在 2021-22 之前时，没有 lineups，合格季 IMP 退回纯 SPM。只影响 2022-23 评估季。
  - 以 2021-22 为末季的衰减 APM 只有 1 季。
- **实验里的年龄曲线每折重拟合。** 只用 ≤ 评估季前一季的相邻赛季对，2015-16 起，与 fit-impact 同法。线上曲线用的是全部 11 季。
- **线上阵容榜和实验的现状口径不一样。** 线上阵容榜对没有 IMP 的人用的不是 −0.5，而是 `liveRosterRankings` 的 `estimateImpact`：统计栏 SPM 按 K=38 场收缩到人群均值，标注「估计值（未验证）」。
  - 本实验的现状口径（回测里的 −0.5）与线上阵容榜并不相同。
  - 所以「回退 vs 线上现行估计」这个比较没有做过。
  - 伤病扣分影子（`server/injury-elo-params-v1.json`）与 Elo 侧用的仍是 −0.5。
- **2025-26 已被多个实验看过**，不是全新留出。

## 做了什么（代码）

- `server/impFallback.mjs`：规则核心，纯函数。
  - `fallbackPriors` / `fallbackValue`，实验与生产口径共用。
  - 另有 `productionFallback`，只给上表的「生产口径」列用，**没有接进 ingest**。
- `server/impFallbackLab.mjs`：`labValuesUpto`。
  - 原先 `scripts/injury-elo-lab.mjs` 与 `scripts/roster-results-backtest.mjs` 里各抄一份的 `valuesUpto`，抽成了这一个函数。
  - 两份回测改用它后，输出逐字不变（只有时间戳不同；`data/injury-elo-lab.json` 逐字节相同）。
  - `RR_PRIOR=continuity` 的输出也不变。
- `server/impact.mjs`：`apply` / `impactOf` 新增 `ageYears`（默认 `aged ? 1 : 0`，ageYears=1 与 aged 逐位相同）。
- 两份回测新增导出钩子：`INJURY_ELO_DUMP` / `RR_DUMP` + `IMP_FALLBACK=primary|sens`。不设置时行为不变。
- 测试：`tests/impFallbackLab.test.mjs`，9 项，覆盖：
  - 合格季与 g 的计数、整季缺阵；
  - 年龄逐岁平移、向 μ 收缩（不是向替补级）；
  - K=20 混入、敏感性；
  - 新秀和上季 ≥ 20 场的人不动；
  - 不读未来赛季；
  - `labValuesUpto` 与原 `valuesUpto` 逐位相同；
  - 生产口径的公式。

  `npm test` 全部 491 项通过。

## 如果以后想再试

不要在这份数据上改参数重跑，那就成了挑结果。可以考虑：

- 做一次新的预注册，针对「球星复出」这一具体场景，例如只对复出后前 N 场、且合格季 IMP 高于均值的人；
- 或者等 2026-27 季中积累前向样本，用影子运行对比回退值与 `estimateImpact`。
