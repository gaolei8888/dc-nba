# IMP 改进实验（2026-10-28）

> 本节「预注册」在看任何结果之前写好并单独提交；结果与结论写在后面的章节里，预注册内容不改。

## 预注册

### 共同口径（与 `fit-impact` / `impact-shrink-lab` 完全相同）

- 4 个赛季对：2021-22→2022-23 … 2024-25→2025-26。
- 球员范围：两季单季 APM 回合 ≥500，第 N 季 ≥20 场且场均 ≥10 分钟（`rowsFor`），每对约 333 人。
- 两把尺子：次季单季 APM（`computeApm` λ=6000，只有进攻方五人）、次季裸 on/off（`onNet − offNet`）。打分是 Pearson 相关。
- SPM 训练时剔除第 N 季（`trainSpm(held)`，λ=3000，目标为单季 APM，样本门槛同 `buildSamples`）。
- **基线 = 现行 IMP（收缩后）**：`0.35·衰减APM + 0.65·SPM`，再按第 N 季出场分钟向人群 SPM 均值收缩（k=3200）。复现值应为次季 APM 0.4705、次季 on/off 0.3356。
- 每个变体的所有可调参数（含分钟收缩 k ∈ {1600, 3200, 6400}）只用**留一赛季对**选：在其余 3 对上按两尺平均选，只在留出对上打分。网格里平局取先出现的那个（网格按「离现状最近」排在前面）。
- **采纳规则**：留一对结果相对基线，两把尺子的 4 对平均 Δ 都 > 0，且任一尺子输（Δ < 0）的赛季对不超过 2 对（输 ≥3 对即不采纳）。
- 球队层面（只报告，不进规则）：采纳候选在延续度回测的「纯阵容」与「延续度混合」两族里替换球员价值，看留一赛季 log loss；若显著变差（95% 区间整体 > 0）则不采纳。
- 不使用任何盘口数据；不抓 stats.nba.com / nba.com。

### 实验 1：APM 权重随回合数增长（DARKO 式）

`IMP = SPM + w_i·(APM − SPM)`，`w_i = wmax · n_i/(n_i + c)`，n_i 为衰减 APM 背后的（半衰期加权）回合数。
网格 wmax ∈ {0.35, 0.5, 0.7, 1.0}，c ∈ {0（= 常数权重）, 1000, 2000, 4000, 8000, 16000, 32000}，再乘 k ∈ {1600, 3200, 6400}。wmax=0.35、c=0、k=3200 即基线。

### 实验 2：攻防分开

- 先确认 APM 的防守侧是否可得：`lineups_*` 每行有该五人组的 `off` 与 `def`，`computeApm` 已分别解出 o、d；`stints_*` 每段有攻守双方十人。所以 D-APM 能从同一份数据得到（但仍无对手调整，见实验 7）。
- O-SPM / D-SPM：同一组特征、同一 λ，目标分别是单季 APM 的 o 与 d。（岭回归对 y 线性，所以 O-SPM + D-SPM 恒等于现行 SPM；差别只来自两侧各自的权重与收缩。）
- 2a：`IMP = Σ_side shrink_side(SPM_side + w_side·(APM_side − SPM_side))`，w_O, w_D ∈ {0.2, 0.35, 0.5, 0.65}，k_O, k_D ∈ {1600, 3200, 6400}，各侧向本侧人群均值收缩。
- 2b：在 2a 上再让两侧 SPM 的 λ 各自可选 ∈ {1000, 3000, 10000}。

### 实验 3：SPM 作为 APM 岭回归的先验（EPM/LEBRON 式）

在衰减 APM（lineups，3 季，半衰期 1）里解 β − prior，prior_O = O-SPM、prior_D = D-SPM（来自实验 2 的分侧模型；对照组按旧做法 SPM/2 各半）。
先验取该球员在第 N 季的 SPM；第 N 季不够门槛的取窗口内最近一季够门槛的；都没有则 0。
- 3a：IMP = 带先验 APM，直接按分钟收缩，不再混合。λ ∈ {3000, 6000, 12000, 24000, 48000, 96000}，先验拆法 ∈ {分侧, 各半}，k 同上。
- 3b：再与 SPM 线性混合，w ∈ {0.35, 0.5, 0.7}。

### 实验 4：运气调整（对手三分、罚球按期望值）

需要逐回合的投篮/罚球事件。先查本机与 GB10 缓存里有没有原始 play-by-play；`stints_*` 只存了每段得分与估算回合，若没有原始事件且不能批量抓取，就记为未做。

### 实验 5：年龄曲线

Delta 法：在训练用的 3 个赛季对上，取两季都够 SPM 门槛的球员，`Δ = IMP_收缩前(N+1) − IMP_收缩前(N)`，权重为两季出场分钟的调和均值，拟合连续分段线性 g(age)，节点 {23, 27, 31}，年龄截断到 [19, 38]。
预测 = 现行收缩 IMP + α·g(age)，**α=1 是采纳判据用的版本**；α ∈ {0.5, 1.5, 2} 只作敏感性。
已知偏差：只用两季都在的球员（幸存者偏差，衰退快的老将早退会让老年段 g 偏乐观）。

### 实验 6：逐项稳定化（LEBRON 式 padding）

拿不到逐场球员 box，做不了真正的折半信度。改用同样不看目标的季内矩估计：对每个特征（每 36 分钟速率），
在该季所有出场 ≥100 分钟的球员上回归 `(f_i − f̄)² = σ² + c / m_i`，padding = c/σ²（单位：分钟）。
每项速率先收缩：`f' = (m·f + pad·f̄)/(m + pad)`，f̄ 为该季分钟加权联盟均值（数据里没有位置，只能向联盟均值收缩），
SPM 在收缩后的特征上重训与应用，其余流程不变。padding 只由季内统计栏决定，**不在目标上调**；
乘子 α ∈ {0.5, 2} 只作敏感性，采纳判据用 α=1。

### 实验 7：双侧（对手调整）RAPM

此前结论：球员评分与队净效率相关 0.589→0.425，但预测上打平（t=1.45）。只有当实验 3 的机制让它几乎零成本时才重测。
实测本机 3 季衰减段级 RAPM 一次约 1.3 秒，所以重测：用 `stints_*` 的衰减 RAPM 代替衰减 APM，
- 7a：线性混合 w ∈ {0.2, 0.35, 0.5} × λ ∈ {2000, 6000, 20000}；
- 7b：带分侧 SPM 先验，λ ∈ {6000, 12000, 24000, 48000, 96000}，不混合或 w ∈ {0.5, 0.7}。
注意：次季 APM 这把尺子本身无对手调整，偏袒 APM 一方。

### 实验 8：统计栏那一半也做多季加权（追加，仍在看任何结果之前）

起因：SPM 只看第 N 季，APM 却是 3 季衰减。Ja Morant 2025-26 只打 20 场且状态差（TS .521），他的 IMP 几乎全由这一季决定（收缩前 −0.79），而 2022-23、2024-25 的两个正常赛季没进来。

做法：只改**应用**，SPM 的训练仍是单季样本（与现状同）。
- 8a（SPM 层面）：`SPM_multi = Σ_j d_j·m_j·SPM_j / Σ_j d_j·m_j`，j = N, N−1, N−2 中该球员 SPM 有定义（≥20 场、场均 ≥10 分钟）的赛季，m_j 为该季出场分钟。
- 8b（逐项速率层面）：把各季的每 36 分钟特征按 d_j·m_j 加权平均后再套 SPM，出场不足 20 场的赛季也能按分钟少量计入（应用门槛仍看第 N 季）。
- 衰减 d_j：Marcel 5/4/3（归一为 1, 0.8, 0.6），或指数半衰期 h ∈ {0.5, 1, 2} 季，或等权；「只用第 N 季」即现状。
- 分钟收缩的证据量 m 可选：第 N 季分钟（现状）或有效分钟 Σ d_j·m_j；与 k ∈ {1600, 3200, 6400} 一起按留一对选。
- 第一对（2021-22→2022-23）没有更早的赛季缓存，只有第 N 季，等于现状；第二对只有 2 季。逐对表照列并注明。
- 组合时与实验 5（年龄）、实验 6（padding，8b 用 padding 后的特征）交叉。

#### 实验 8 扩展：更长的记忆（追加，仍在看任何结果之前）

用户要求「球员价值要参考长期表现」。把记忆长度本身交给数据，规则不变：
- 8a/8b 的窗口 span ∈ {3, 5}（5 = 缓存里能拿到的全部往季，最多第 N 季加 4 个往季），衰减另加近乎等权的 h ∈ {3, 5}。
- 8c（APM 那一半）：衰减 APM 的 span ∈ {3, 4, 5} × 半衰期 ∈ {1, 1.5, 2, 3} 季（现状 3 季 / 1 季）。仍按回合加权，伤病短季自然权重小。
- 每对实际能用的赛季数受缓存限制（lineups / impact 都从 2021-22 开始）：输入季 2021-22 只有 1 季，2022-23 有 2 季，2023-24 有 3 季，2024-25 有 4 季。所以 span>3 只影响最后一对、span>2 只影响后两对——逐对表照列，结论要按这个打折。
- 如果更长的记忆被采纳，老赛季需要年龄调整的问题在实验 5 的结论里一并讨论（本轮不额外拟合「逐季先做年龄平移再平均」）。

#### 实验 5 × 8 细化：随年龄调整的长记忆（追加，仍在看任何结果之前）

用户指出：年龄增长运动能力下降，长记忆必须先做年龄调整。追加三个变体，规则不变：
- **5b 逐项年龄曲线（DARKO 式）**：对每个特征（每 36 分钟速率，含 blk/stl/oreb/dreb 这类运动能力项与 ast/tov/tsAdd 这类技术项）分别用 delta 法拟合 g_j(age)（连续分段线性，节点 23/27/31，截断 [19, 38]；只用相邻两季都有 ≥100 分钟的球员；权重为两季分钟的调和均值）。预测时把第 N 季的特征平移 g_j(age_N) 再套 SPM（APM 那一半不动）。曲线只在训练用的 3 个赛季对上拟合（若历史回填到位，另加回填赛季之间的相邻对——它们只含统计栏，不涉及任何目标）。
- **8d 年龄对齐后再多季平均**：8b 的逐项多季平均里，第 N−k 季的特征先平移累计年龄增量 Σ_{a=age_{N−k}}^{age_{N+1}−1} g_j(a)，对齐到目标赛季（N+1）的年龄，再按 d_j·m_j 平均。衰减/窗口网格同 8b。另报只用总值年龄曲线（实验 5 的 g）对 8a 各季 SPM 做同样对齐的版本（8e）。
- 实验 5 本身的预测口径同理改为「对齐到 N+1 岁」：单季时就是加 g(age_N)，与原预注册一致。
- **幸存者偏差**：只用相邻两季都在的球员，衰退最快的人退出样本，会让老年段曲线偏乐观。主口径按两季分钟调和均值加权（两季都打得多的人权重大）；敏感性另报 (i) 不加权，(ii) 粗修正：第 N 季够门槛、第 N+1 季消失或不足 100 分钟的球员，按该季够门槛球员第 10 百分位的值补一个「次季」。敏感性只报，不参与判定。
- 报告各年龄段曲线（逐项与总值）以及老将（LeBron、Curry、Durant、Harden、Lillard）与年轻上升球员的前后对比。
- 2015-16~2020-21 的统计栏回填若在本次运行前落到主仓库 data/history，则 5/6/8 用更长的历史重跑并注明；否则只用现有 5 季，并说明。
