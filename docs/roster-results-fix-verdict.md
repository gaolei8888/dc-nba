分层与阶段的读法：

- **(ii) 是唯一显著的一层，这与机制一致。**
  - 球星复出后，先验马上把他算回来，R0 的战绩项里却还留着他缺阵时的比赛。
  - R1 把这些比赛折回「今天的阵容」口径，正好修这一处。
- **(i) 长期缺阵期间收益很小**（−0.0009）。机制上本来就该如此，见下节。
- **开季 0–9 场没有收益**（+0.0004）。此时战绩项权重小，可修的东西也少。
- 收益出现在 10 场以后，那时战绩项开始占大头。

## 机制：评审说的「重复扣」在阵容榜上只成立一半

- **缺阵一直持续到今天时，阵容榜并没有重复扣。**
  - 先验是今天缺人的阵容，战绩项是缺人打出的比赛。两者描述的是同一支缺人的队，加权平均不会把缺阵扣两遍。
  - 单测「持续缺阵：R1 与 R0 一致」锁定了这一点：今天还缺他、过去也缺他时，修正量 D_pre − D_post = 0。
  - 这与 Elo 不同：Elo 本身吸收了缺阵，赛前再扣一次才是真重复。
- **真正出错的是「阵容变了」的那些时刻**：
  - 复出：先验加回来了，战绩项没加回来，评级偏低。这就是 (ii)。
  - 新缺阵：过去的满员比赛高估了今天的队，先验扣了，战绩项没扣，评级偏高。
  - 还有轮换外的人偶尔不上（DNP-CD）。D_post 有 46% 的队·场是负的：缺的是价值低于平均的替补，分钟重分给更好的人，阵容分反而上升。
- 所以修法的作用面比预期窄：R1 只在阵容变化的时刻起作用，而且量级被 K=12 的先验与近期加权稀释。
- 这也解释了为什么 injury-elo 的 A 对 P1 有 −0.0014，这里对 R0 也只有 −0.0014 左右：两边都只修到了转折点上的那一小块。

## 方法（预注册摘要；细节见预注册文件）

**修法**：

- 对每场已完赛比赛 g：残差 = m − [(r_主 + Δ_主) − (r_客 + Δ_客) + 主场项]，其中 Δ_t = s·(D_pre_t(今) − D_post_t(g))。
- 三个阵容分都用线上 batch1 分钟模型、同一组 rows、同一个联盟均值：
  - **H**：满员，只看轮换概率，即 `healthyRosterRating`；
  - **p**：先验，乘 P(出场|赛前状态)，即线上 `total`；
  - **A**：出场概率换成当场是否上场（stints，赛后）。
- D_pre = H − p，D_post = H − A，都带符号。
- 实现：在「满员当量」空间里调用原来的 `resultsUpdate`：
  - 先验 p + s·D_pre；
  - 每场净胜分 m + s·(D_post_主 − D_post_客)；
  - 解出后减回 s·D_pre。
- D 全为 0 或 s = 0 时与 R0 **逐位相同**：单测锁定，脚本运行时对 4 季 × 2 口径也逐场核对，最大差 0。
- K=12、近期加权 0.4^(天数/60)、sd 12、主场 1.6、休息 1.8，各方案相同。

**协议**：

- 2021-22 只热身，评估 2022-23 ~ 2025-26，共 4920 场。
- 每个比赛日只用更早日期的赛果。
- LOSO：其余三季选 s，留出季打分。
- 最终留出：即 LOSO 的 2025-26 那一折，参数在 2022-25 上选。
- bootstrap B=2000、seed 7，按场与按比赛日分块各报一次。日内各场相关（同一天的伤病报告、同一批赛果更新），按日分块的区间略宽，是采纳依据。

## 数据缺口

**没有阻碍实验的缺口**：先验可以只用赛前信息构建（strict），不需要 NEEDS_CONTEXT。剩下的近似：

1. **开季名单**：
   - 「上季最后效力该队、且本季首次出场也为该队」用到了他本季第一次为谁出场，作为开季名单的代理。
   - 开季名单在首场前公布，属于赛前公开信息，但我们没有带时间戳的历史名单（`rosters_*.json` 是赛季末快照）。见预注册偏离 1。
2. **赛季中的签约 / 交易**：strict 在首秀的下一场才把新人算进来，被交易的人在为新队出场后才出列。
   真实世界里赛前就知道交易，所以 strict 在这几场里信息比真实少，是保守的方向，不是泄漏。
3. **没有 stints 的比赛**（约 3%）：D_post 记 0，相当于对这些场不做修正。
4. **伤病报告缺失**（1640 / 9552 个队·场）：D_pre = 0，先验按全员可出场。这与线上无报告时的行为一致。
5. **分钟模型常数**（rotationMinutes / 收缩常数）对 2021-26 是样本内，沿用原回测，不是本次引入的。

## 局限

- **R0 的 K=12 本身是在这四季上选的**：固定 K=12 的 R0 比原结论的逐折选 K 版本对 P0 更好（−0.0072 vs −0.0062）。
  R1 用同一个 K，比较是公平的，但「对 P0」这一列偏乐观。
- **差 0.0002 没过线，不能说「修法无效」**：
  - 点估计四季中三季为负；
  - (ii) 层显著；
  - 留出季 −0.0021。
  - 只能说：按预注册的严格程度，现有四季的样本量证明不了它在全体比赛上有收益。
- **规则是按日分块定的**：按场的上界是 +0.0001，同样不过线。
- **legacy 与 strict 用的是同一份分层**（按 strict 上下文定义），legacy 的分层数字只作参照。
