## 六个问题

### 1. 当前模型有没有正向 Edge？

**没有证据。** 三条迹象都指向「没有」。它们来自同一批比赛、同一个模型，不是三条独立的证据：

- 概率不如去水后的市场准（已复现，C2）。每个切分、两个情景，模型的 Brier 与 LogLoss 都比市场差：

  | 情景 / 切分 | 场次 | 模型 Brier | 市场 Brier | 模型 LogLoss | 市场 LogLoss |
  |---|---|---|---|---|---|
  | 收盘 训练 2022-23 | 1230 | 0.2261 | 0.2163 | 0.6438 | 0.6230 |
  | 收盘 验证 2023-24～2024-25 | 2459 | 0.2105 | 0.1989 | 0.6080 | 0.5815 |
  | 收盘 测试 2025-26 | 1229 | 0.2063 | 0.1948 | 0.5994 | 0.5711 |
  | 开盘 选参 2023-24 | 1228 | 0.2113 | 0.2038 | 0.6103 | 0.5937 |
  | 开盘 验证 2024-25 | 1229 | 0.2095 | 0.2047 | 0.6054 | 0.5951 |
  | 开盘 测试 2025-26 | 1229 | 0.2062 | 0.1987 | 0.5991 | 0.5799 |

  市场概率 = 同一家、同一时点两侧钱线按比例去水，只用于比谁更准，不用于结算。
- 每场押模型看好的一方（A-model），按实际价结算，每一季的命中率都低于平均盈亏平衡概率（已复现，C3）。见下文「66% 为什么不等于盈利」。
- 预选策略在测试期 ROI 为负（已复现，C1）：收盘 −10.19%，开盘 −3.24%。

### 2. 哪个市场最有潜力？

**只评估了独赢盘，无法比较。** 让分与大小分没有评估，原因是数据不够，不是看过结果后放弃：

- 让分：历史让分**价格**缺失（`odds_*.json` 只有盘口数值；`books_*.json` 的 `trimItem` 只存让分数值与钱线），无法按实际价结算。
  49.1% 只是「统一按 −110」假设下的命中率（已复现，C5；见下文「49.1% 复核」）。
- 大小分：`odds_<季>.json` 每场只有一家公司的一个值，不带时点标签（已复现，C6）。2022-23 与 2023-24 的来源几乎都是 BetfairSportsbook（交易所，按规则不用于定价），
  2024-25 为 ESPN BET，2025-26 主要为 Draft Kings（974）与 ESPN BET（249）。单家、单时点、来源逐季变化，撑不起一个可信的回测。
- 用户决定本期只做独赢盘（README 记载：spec `docs/superpowers/specs/2026-10-29-moneyline-backtest-design.md`「非目标」）。

### 3. 哪种策略回测 ROI 最高？

**只在选择期选，测试期只报告一次。** 参选的是 6 个固定注策略（B-edge2/3/5/7/10、C-ev），选择期 ROI 最高且注数 ≥ 100 者入选（已复现，C1）：

- 收盘情景：在验证期（2023-24 + 2024-25）选出 **B-edge7**（验证期 828 注、ROI −6.04%）。6 个候选在验证期**全部为负**，选出的只是「亏得最少」的。测试期 431 注，ROI **−10.19%**，95% 区间 [−23.48%, +2.71%]。
- 开盘情景：在选参期（2023-24）选出 **B-edge10**（163 注、ROI +5.21%）。验证期（2024-25）218 注 +17.76% [−7.31%, +44.86%]；测试期 221 注，ROI **−3.24%**，95% 区间 [−20.95%, +15.13%]。

「ROI 最高」这条选择规则偏向注数少、方差大的高阈值规则（两个情景都选了阈值最高的一档附近），所以下面列出全部策略的完整结果。

### 4. 扣除费用 / 滑点后是否仍盈利？

**扣费前就不盈利，扣了更差。** 默认成本为 0（手续费 0、滑点 0、不限额），滑点敏感性（已复现，C1）：

| 情景 | 策略 | 滑点 0 点 | 滑点 5 点 | 滑点 10 点 |
|---|---|---|---|---|
| 收盘 | B-edge7（431 注） | −10.19% [−23.48%, +2.71%] | −11.60% [−24.73%, +1.15%] | −12.98% [−25.93%, −0.44%] |
| 开盘 | B-edge10（221 注） | −3.24% [−20.95%, +15.13%] | −4.83% [−22.40%, +13.23%] | −6.39% [−23.66%, +11.36%] |

收盘情景加 10 点滑点后，区间上界也低于 0。

### 5. 证据是否足以支持真实资金投入？

**不足。** 按预先写定的规则（测试期扣默认成本后 ROI 的 95% 按比赛日 block bootstrap 区间下界 > 0，且注数 ≥ 300；前向账本另需同样条件）：

- 收盘测试期：431 注 ≥ 300，但区间下界 −23.48% < 0 → **无证据**（已复现，C1，结论码 `srv.ml.verdict.test.noEvidence`）。
- 开盘测试期：221 注 < 300 → **注数不足，无证据**（已复现，C1，`srv.ml.verdict.test.tooFew`）。
- 前向账本：线上 10 注（2026-10-28 一个比赛日）< 300 → **无证据，样本不足**（已复现，线上 `srv.ml.verdict.live.tooFew`；见「前向账本」）。

三项都不满足，不应投入真实资金。

### 6. 还需多少样本才能更有把握？

**按观测到的 ROI，多少样本都不会显著为正。** 两个测试期观测 ROI 都 ≤ 0，功效分析返回「不适用」（μ ≤ 0 时无解）。
如果真实 ROI 是正的某个值，按测试期观测到的每注波动（α = 0.05、功效 0.8）大约需要（已复现，C2）：

| 情景 | 每注 σ | deff | ROI 1% | ROI 2% | ROI 3% |
|---|---|---|---|---|---|
| 收盘 B-edge7 | 1.461 | 0.844 | 141,349 注 | 35,338 注 | 15,706 注 |
| 开盘 B-edge10 | 1.523 | 0.796 | 144,781 注 | 36,196 注 | 16,087 注 |

一个赛季只有 1230 场，这类高阈值策略一季约 160–450 注（已复现，C2：最少为开盘选参期 B-edge10 的 163 注），ROI 3% 也要几十个赛季。按日聚类没有放大方差（deff < 1，已复现，C2）。

## 校准：walk-forward 拟合 σ vs σ = 12（已复现，C1 报告的 `fits[].calibration`）

重放模型胜率 = Φ(分差 / σ)。每季三组概率比较：`fitted` = walk-forward 拟合的主场、休息、σ；`sd12` = 同样的 walk-forward 分差、σ 固定为 12；
`allDefaults` = 主场 1.6、休息 1.8、σ 12 全用全局默认值。Brier 与 LogLoss 在报告文件里只存到 4 位小数。

| 赛季 | 参数来源 | 主场 | 休息 | 拟合 σ | fitted Brier / LogLoss | σ = 12 Brier / LogLoss | 全默认 Brier / LogLoss |
|---|---|---|---|---|---|---|---|
| 2022-23 | **样本内**（用本季自己拟合） | 2.29 | 1.97 | 12.70 | 0.2261 / 0.6438 | 0.2261 / 0.6439 | 0.2268 / 0.6452 |
| 2023-24 | 拟合自 2022-23 | 2.29 | 1.97 | 12.70 | 0.2114 / 0.6106 | 0.2111 / 0.6098 | 0.2105 / 0.6085 |
| 2024-25 | 拟合自 2022-23～2023-24 | 2.20 | 2.16 | 11.77 | 0.2094 / 0.6050 | 0.2094 / 0.6052 | 0.2090 / 0.6043 |
| 2025-26 | 拟合自 2022-23～2024-25 | 1.99 | 2.32 | 11.41 | 0.2061 / 0.5990 | 0.2063 / 0.5996 | 0.2059 / 0.5985 |

- σ 拟合值在 11.41～12.70 之间，与 12 的差别对概率质量影响极小（每季 LogLoss 差 ≤ 0.0008）。spec 里「σ = 12 胜率可能过于自信」的担心没有得到支持：分差残差的 SD 不等于胜率换算的最优 σ。
- 三个样本外季里，全默认参数的 LogLoss 都比 walk-forward 略好（0.6085 vs 0.6106，0.6043 vs 0.6050，0.5985 vs 0.5990）。但主场 1.6 取自 2024-25 / 2025-26 的实测，休息 1.8 也用到了评估季的数据（README 记载：`README.md`「模型实验室」节的逐年测量与 `server/predict.mjs` 注释，`docs/ats-491-audit-output.txt` [6] 复核）；σ 12 的来源 README 没有说明，**待验证**。所以这个比较对默认值有利。按裁定 M16，没有因此改成别的窗口。
- 「全默认」一栏与重放快照的逐季 Brier 0.2268 / 0.2105 / 0.2090 / 0.2059 一致（已复现，C5）。

### 49.1% 的口径复核

（已复现，C5，输出与 `docs/ats-491-audit-output.txt` 逐行一致）

- 口径：模型预测分差减盘口隐含分差得 edge，edge > 0 押主队让分，否则押客队；命中率 = 赢 / (赢 + 输)，push 不进分母。
- 样本：4908 场有盘口，赢 2391、输 2471、push 46，分母 4862；**命中率 49.18%，95% 区间 [47.77%, 50.58%]**。
- README 记载 49.12%（±1.41）。差 0.06 个百分点；不是同日修复造成的（修复前后一致），推测来自较早的数据版本，**原因待验证**（没有记录可证）。
- 区间包含 50%，所以不能说「显著比随机差」；但区间上界低于 −110 下的打平线 52.38%，相对抽水是显著不够。
- 盘口来源逐季不同：2022-23 / 2023-24 几乎全是 BetfairSportsbook（交易所），2024-25 为 ESPN BET，2025-26 主要为 Draft Kings。让分价格缺失，所以「按 −110」换算的 ROI −6.12% 只是假设情景，不是历史实际收益。

### 66% 胜负命中率为什么不等于盈利

README 记载模型胜负命中率 66.26%（本次重放 66.32%，已复现，C5），盘口自己是 68.40%。

**README 里有四个旧数与当前数据不符**：66.26% / McNemar χ² 15.70 / 盘口独对 397 场 / 让分 49.12%（README 记载：`README.md`「对标博彩盘口」节与模型实验室节），本次重放为 66.32% / 14.87 / 394 / 49.18%（已复现，C5）。同日修复前后逐位一致，所以不是修复造成的；推测来自较早的数据版本，原因**待验证**。README 这几行不在本任务范围内，未改，已上报。本报告一律用重放值。

命中率高不等于赚钱，因为押热门要付高价：押 −250 要赢 71.4% 才保本。按实际钱线每场押模型看好的一方（A-model），收盘情景逐季（已复现，C3）：

| 2023-24 | 1230 | 66.02% | 69.14% | −3.12 pp | −5.46% |
| 2024-25 | 1229 | 67.13% | 69.52% | −2.39 pp | −3.32% |
