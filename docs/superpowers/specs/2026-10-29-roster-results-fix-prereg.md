## 问题

线上阵容实验榜（`server/rosterResults.mjs` + `server/liveRosterRankings.mjs`，冻结参数 `server/roster-results-params-v1.json`）：

r_i = (K·p_i + Σw·(m − 主场项 + r_对手)) / (K + Σw)，K = 12，w = 0.4^(天数/60)。

- 先验 p_i 是**今天**的阵容分（IMP × 预计分钟），已扣掉今天伤病报告上的缺阵；
- 战绩项用**原始终场净胜分** m，不管那场谁上了。

于是（与 `injury-elo` 分支 R-check 的结论相同）：
1. 球星缺阵期间打出的比赛照原样拉低战绩项，今天的先验又扣一次 → 重复扣；
2. 球星复出后，那些缺人比赛还留在加权均值里，约 60 天后仍有 40% 权重 → 不还分。

## 修法（R1）

对每场已完赛比赛 g，残差改为相对「当场实际上场的人」的期望：

残差 = m − [(r_主 + Δ_主(g)) − (r_客 + Δ_客(g)) + 主场项]，Δ_t(g) = s·(D_pre_t(今) − D_post_t(g))。

- **H_t(g)**（满员）= 比赛 g 的赛前上下文里的阵容分，但只用轮换概率、不乘伤病出场概率：
  即 `healthyRosterRating(projectExpectedRotation(rows))`，与先验同一个 rows、同一套分钟模型、同一个联盟均值。
- **先验** p_t(g) = `rosterRating(projectExpectedRotation(rows))`，即线上口径（分钟 × 轮换概率 × P(出场|赛前状态)）。
- **D_pre_t(g) = H_t(g) − p_t(g)**：赛前已知的缺阵扣分（只用赛前报告）。
- **A_t(g)**（实际）= 同一 rows，但出场概率改为「当场是否上场」（1/0，来自 stints），轮换概率不变。
- **D_post_t(g) = H_t(g) − A_t(g)**：当场实际缺阵扣分（赛后信息，只进以后比赛的战绩项与分层）。
- D 都带符号，不截到 0（与先验本身不截断一致）。
- 实现上等价于在「满员当量」空间里解同一个方程：先验 p + s·D_pre，每场净胜分 m + s·(D_post_主 − D_post_客)，
  解出后减回 s·D_pre。所有 D = 0 时与 R0 **逐位相同**（单测锁定）。
- 「今」= 每队最近一次赛前上下文（与 R0 的先验取法相同：先验与 D_pre 一起沿用）。
- 对手项用同一张后验榜（SRS 式），K、近期加权与 R0 完全相同。
- 胜率 = Φ((r_主 − r_客 + 主场 1.6（中立 0）+ 休息×1.8) / 12)，即 `rosterResults.gamePred`，各方案相同。

## 方案

| 方案 | 定义 | 参数 |
|---|---|---|
| **R0** | 现阵容榜：K = 12、近期加权 0.4^(天数/60)、原始净胜分 | 固定 |
| **R1** | 上式，s = 1 | 固定 |
| **R1s** | 上式，s ∈ {0.5, 0.75, 1.0} | 每个 LOSO 折只在训练季上按 log loss 选；并列取较小 s |

## 数据与赛前性

- 球员价值：上季收缩 IMP（`valuesUpto(X−1)`，与 `scripts/roster-results-backtest.mjs` 逐行相同）。
- 分钟与轮换：`server/minutesLab.mjs` + `rotationMinutes` + `projectExpectedRotation`（线上 batch1 口径）。
- 赛前伤病状态：`minutesLab` 的链（当天北京 22:00 → 前一天北京 06:30，`picks_lag15`）。
  **另加时间核对**：链上每份候选报告必须满足「标注时间 + 15 分钟 ≤ 决策时点（北京 22:00）< 开赛」，开赛时间取该日 22:00 报告上的 Game Time。
  不满足的报告从链上剔除（实现为 `minutesLab` 的可选参数，默认不启用，线上与旧回测不受影响），并报告剔除次数。
- **候选名单（主口径 strict）**：现有 `minutesLab` 的候选名单含两处赛后信息：(a) 把**本场实际上场的人**加进候选；
  (b) 用「之后的出场记录」决定转会窗口（新人提前 5 场入列，之后被交易的人在最后一场后出列）。这违反「先验只用赛前信息」。
  主口径改为 strict（同样是 `minutesLab` 的可选参数，默认 legacy 不变）：
  - 候选 = 本季在本场日期之前最近一次为该队上场的人，或本季尚未上场、上季最后效力该队的人；
  - 并且：在该队最近 10 场里上过场，或在本场的赛前报告上，或该队本季已赛 < 10 场；
  - 不加入本场实际上场的人，不看任何未来出场。
  - 本季首场才登场、此前不在候选里的人，不进先验，也不进 H / A / D（D 只量「候选里谁没上」）。
- **次口径 legacy**：沿用现有候选名单，即 `docs/roster-results-update-verdict.md` 的原样先验。所有方案在 legacy 下也全跑一遍，只报告；
  同时核对 R0（legacy）的四季合并 log loss 与 `docs/roster-results-backtest-batch1-output.txt` 的 K=12 近期加权（0.6068）一致。
- 实际上场名单来自 stints（赛后，合法地用于以后比赛的更新）。没有 stints 的比赛：两队 D_post 记 0；
  没有赛前上下文的队·场：先验与 D_pre 沿用该队上一次的值（与现回测相同），开季首场就没有时退回 continuity 口径、D_pre = 0。

## 协议（与 roster-results-update-verdict 相同）

- 2021-22 只做热身；评估 2022-23 ~ 2025-26（4920 场）。
- 每个比赛日开赛前，只用更早日期的完赛结果求后验。
- LOSO：每折在其余三个评估季上选参数，在留出季打分，四折合并。
- 最终留出：2022-25 选参数，只在 2025-26 打分（即 LOSO 的 2025-26 那一折）。
- 配对 bootstrap B = 2000、seed 7：**按场**（`fusionLab.bootstrapCI`）与**按比赛日分块**（整日的比赛一起重抽，统计量 = 抽中各场 Δ 之和 / 场数）都报告。
- 指标：log loss（主）、Brier、净胜分 MAE。

## 分层（预注册）

- 轮换球员：该场赛前上下文里满员分钟（healthyMinutes）≥ 20 的候选。缺阵 = 当场没上（stints）。
- (i) 比赛中任一队有轮换球员处在 ≥ 5 场的连续缺阵段里；
- (ii) 不属 (i)，且任一队处在「某轮换球员结束 ≥ 5 场缺阵段、复出那场起」的 10 场内；
- (iii) 其余（含无 stints 的比赛）。
- 实现沿用 `injury-elo` 分支 `strataOf` 的同一算法（(i) 优先），按队的本季比赛顺序计数。
- 另报告阶段（已赛 0–9 / 10–19 / ≥20）与逐季。

## 采纳规则（影子模式）

R1(s*) 进影子模式，当且仅当三条同时满足：

1. LOSO 合并 Δlog loss（R1s − R0）的**比赛日分块** bootstrap 95% 区间上界 < 0；
2. 最终留出 2025-26 的点估计 Δ ≤ 0；
3. 第 (iii) 层点估计 Δ ≤ +0.002。

主口径 strict 决定；legacy 只报告。对 P0、A(0.75) 的比较只报告，不作条件。影子冻结的 s 用四季合并选出的值。

## 单测（`tests/rosterResultsFixLab.test.mjs`）

- 无缺阵（D 全 0）时 R1 与 R0 逐位相同；全员上场且无报告时 D_pre = D_post = 0；
- 先验不泄漏：改动本场及以后的 stints / 比分不改变本场的先验与 D_pre；strict 候选不含本场才登场的人；
- s 缩放：s = 0 时等于 R0，s 在满员当量空间里线性进入净胜分；
- 比赛日分块 bootstrap 的基本性质。

## 偏离 1（2026-10-29 07:52 PDT，写代码时、尚未跑任何比较）

strict 候选名单里「本季尚未上场、上季最后效力该队的人」这一条，写的时候没想清楚：不看未来就分不出已经离队的自由球员，
他们会在开季前 10 场留在先验和满员基线 H 里，从不上场，于是 D_post 会把「离队」当成「缺阵」给 R1 记分，污染比较。
改为（只改这一条，其余 strict 规则不变）：

- 开季沿用名单：上季最后效力该队、且本季第一次出场也是为该队的人（即 legacy 的开季沿用规则）。
  这用到了「他本季第一次为谁出场」，属于**开季名单**这一赛前公开信息的代理（开季名单在首场前公布，只是我们没有带时间戳的历史名单）。
  这一近似在结论里列为数据缺口。
- 赛季中的两处赛后信息仍按原注册去掉：不把本场实际上场的人加进候选；新加入的人从他第一次为该队出场的**下一场**起才入列，
  为别队出场之后立即出列（不再提前 5 场入列、不再按未来的最后一场出列）。
