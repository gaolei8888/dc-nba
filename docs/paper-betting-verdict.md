## 结论

**样本外（2023-24、2025-26，DraftKings，edge ≥ 3%）1596 注，ROI −11.8%，95% 区间 [−19.3%, −4.6%]：稳定亏损。**
胜率 33.1%，保本需要 37.1%；累计 −188.7 注，最大回撤 196.8 注。模型赢不了盘口，不应据此下注。

## 预注册规则（未在评估季上调）

- edge = 模型胜率 − 该家去水胜率；≥ 3% 押 1 单位，按该家含水美式赔率结算。对照 0% / 6%、挑最优价、各家逐一。
- 门槛只允许在 2022-23 看；页面结论只用之后的赛季。2022-23 上 DK ≥3% 为 +0.5% [−10.0%, +10.5%]——即便在允许看的那季也没有可调的信号，门槛没动过。

## 为什么亏

- 概率本身就不如盘口准：每季每家，模型对数损失都比该家去水概率高约 0.02–0.03（DK 2025-26：0.600 vs 0.571）。
  edge 大多出现在模型比市场更看好弱队的时候，所以胜率 33% 而非 50%。
- CLV（按开盘价下注、对收盘）平均为正（DK 2023-24 +1.4 个百分点 [+1.0, +1.8]），但 ROI 仍为负：
  收盘确实往模型那边挪一点，挪得不够付抽水。正 CLV 在这里不是赚钱的证据。

## 口径与已知局限

- 价格时点：2022-23 多数只有 current（视作近似收盘），2023-24 起都有 close；从不用 open 冒充收盘。
- FanDuel 在 ESPN 任何赛季都没有；2024-25 只有 ESPN BET；2025-26 DK 973 场、ESPN BET 299 场。
- **`pickBook` 修复后的 provider 统计没有重算**：`backtest.json` 由 `odds_<赛季>.json` 与 `gamelog_*.json` 生成，
  这两类缓存不在本机，离线重建不了。现有 `backtest.json` 里 2022-23 / 2023-24 的盘口仍是 Betfair 的价（实验室「对标盘口」用的是它）。
  要修：在有 history 缓存的机器上删掉这两季的 `odds_*.json` 重跑 `npm run odds:history`（会重新发约 2500 次 ESPN 请求）再 `npm run dataset`。
  模拟投注不受影响，它直接读 `books_*.json`。
